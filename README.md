# 薪酬拆分计算工具（Salary 1 / Salary 2）

纯本地网页工具：上传表格 → 输入列名和比例 → 自动计算并下载新表格，整个过程不联网、不上传数据。

## 使用方法

1. 双击打开 `index.html`（用 Chrome / Edge 等浏览器）。
2. 点击或拖拽上传 `.xlsx` / `.xls` / `.csv` 表格。
3. 选择需要处理的列名（仅可选择“业务”或“利润额”）；如需指定子表，在“需要处理的子表”中填写子表名（多个用逗号分隔，留空则处理所有子表）。
4. 输入比例（0 ~ 1，例如 0.7）。
5. 点击“开始处理”，页面会显示每个子表的处理摘要和预览。
6. 点击“下载新表格”，得到 `Salary-原文件名.xlsx`。

## 计算规则

对工作簿中选定的子表（留空则对所有子表）：

- 在表头第一行查找用户输入的列名（先精确匹配，再忽略大小写匹配），找不到的子表不处理。
- 找到后，在该表最右侧第一个空列起追加两列：`Salary 1`、`Salary 2`。

每一行数据：

列名仅可选择“业务”或“利润额”。

**“业务”列：**

| 单元格情况 | Salary 1 | Salary 2 |
| --- | --- | --- |
| 恰好 1 个数字且文本含“新装” | 数字 × 比例 | 数字 × (1 − 比例) |
| 恰好 2 个数字且文本含“升级” | (大数 − 小数) × 比例 | (大数 − 小数) × (1 − 比例) |
| ≥3 个数字 / 2 个数字但无“升级” / 1 个数字但无“新装” / 无数字 | 不符合格式，未计算 | 不符合格式，未计算 |

**“利润额”列：**

| 单元格情况 | Salary 1 | Salary 2 |
| --- | --- | --- |
| 单个带正负号的数字（如 +120、-35.5） | 数字 × 比例 | 数字 × (1 − 比例) |
| 其他（无符号、多个数字、非数字等） | 格式不符，未计算 | 格式不符，未计算 |

整行都为空的单元格不处理，保持留空。

Salary 1、Salary 2 的计算结果统一保留两位小数（四舍五入，导出表格中显示两位小数）。

## 文件说明

- `index.html`：页面本体
- `salary-core.js`：计算逻辑（浏览器和 Node.js 通用）
- `xlsx.full.min.js`：SheetJS 本地库（用于解析和生成 Excel，页面离线可用）

## 本地服务器方式（可选）

直接双击 `index.html` 即可使用。若浏览器限制了本地文件，也可以在命令行启动静态服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。
